ChemSort — Installation Guide

Tài liệu chi tiết dành cho developers và testers - Hướng dẫn cài đặt môi trường, chạy và build ChemSort từ mã nguồn.

📌 Lưu ý: Đây là hướng dẫn chạy từ source code, không phải hướng dẫn tải app từ Google Play hay App Store. Repository hiện không kèm APK phát hành công khai.

Mục lục

1. Phạm vi 2. Yêu cầu 3. Lấy mã nguồn 4. Cài công cụ 5. Tải thư viện 6. Android 7. iOS 8. Kiểm tra 9. Xử lý sự cố 10. Phát hành

1. Phạm vi và thông tin phiên bản

1.1. Đối tượng và phạm vi

Hướng dẫn phù hợp nếu bạn cần mở mã nguồn bằng VS Code hoặc Android Studio, chạy ứng dụng trên thiết bị Android/iOS, hoặc build APK/IPA để kiểm thử. Bạn nên biết cách sử dụng PowerShell hoặc Terminal và có hiểu biết cơ bản về Flutter/Dart.

⏱️ Thời gian: Lần cài đầu có thể mất từ vài chục phút đến vài giờ tùy tốc độ mạng và dung lượng Android SDK.

1.2. Cấu hình hiện tại

Thành phần Giá trị trong dự án
Flutter 3.44 trở lên
Dart 3.6.0 đến trước 4.0.0
Android API 26+ (Android 8.0)
Java/Kotlin Java 17, Kotlin JVM target 17
iOS iOS 15.0+
Model yolo11n-cls_data_v2_float32.tflite (~6.2 MB)
App Version 0.1.0+1

2. Yêu cầu môi trường

2.1. Công cụ dùng chung

  • Git để tải và cập nhật mã nguồn
  • Flutter SDK đáp ứng phiên bản dự án
  • VS Code với Flutter/Dart extension hoặc Android Studio
  • ~10 GB dung lượng trống cho Android Studio, SDK, emulator
  • Kết nối Internet lần đầu tải packages và SDK

2.2. Nếu build Android

  • Android Studio hoặc Android SDK Command-line Tools
  • Android SDK Platform/Build Tools tương thích Flutter
  • Android SDK Platform-Tools (có adb)
  • JDK 17 (Android Studio thường cài kèm)
  • Điện thoại Android 8.0+ hoặc Android Emulator
  • USB debugging enabled trên điện thoại thật

💡 adb.exe trên Windows thường ở: %LOCALAPPDATA%\Android\Sdk\platform-tools\

2.3. Nếu build iOS

  • macOS (không thể build iOS trên Windows)
  • Xcode 15+ và Xcode Command Line Tools
  • CocoaPods
  • iPhone chạy iOS 15.0+
  • Team và chứng chỉ ký để chạy trên iPhone thật

❌ Lưu ý: Project hiện tắt Swift Package Manager và dùng CocoaPods. Không bật lại SPM nếu chưa cập nhật cấu hình.

3. Lấy mã nguồn và kiểm tra

3.1. Clone repository

Windows PowerShell:

New-Item -ItemType Directory -Force "$HOME\source\repos" | Out-Null
Set-Location "$HOME\source\repos"
$repoUrl = Read-Host "Nhập URL Git của repository ChemSort"
git clone $repoUrl chemsort
Set-Location .\chemsort

macOS Terminal:

mkdir -p ~/source/repos
cd ~/source/repos
read -r -p "Nhập URL Git của repository ChemSort: " repo_url
git clone "$repo_url" chemsort
cd chemsort

3.2. Kiểm tra các tệp cần thiết

Thư mục gốc phải có:

  • pubspec.yaml
  • lib/, android/, ios/
  • assets/chemsort/yolo11n-cls_data_v2_float32.tflite (model ~6.2 MB)
  • assets/chemsort/labels_9.txt (9 nhãn model)
  • assets/chemsort/chemsort_mapping.json (ánh xạ nhãn)
  • assets/chemsort/flashcards.json (178 flashcards)

Kiểm tra bằng PowerShell:

Test-Path .\pubspec.yaml
Test-Path .\assets\chemsort\yolo11n-cls_data_v2_float32.tflite
Test-Path .\assets\chemsort\flashcards.json

4. Cài đặt công cụ phát triển

4.1. Cài Flutter và kiểm tra PATH

Cài Flutter SDK theo hướng dẫn chính thức, thêm flutter/bin vào PATH, sau đó mở terminal mới:

flutter --version
dart --version
git --version
flutter doctor -v

4.2. Android Studio và Android SDK

  1. Cài Android Studio
  2. Mở SDK Manager và cài Platform, Build-Tools, Platform-Tools, Command-line Tools
  3. Mở Device Manager nếu muốn tạo emulator
  4. Chấp nhận licenses:
flutter doctor --android-licenses

4.3. Xcode và CocoaPods (macOS)

Cài Xcode, mở một lần để hoàn tất cấu hình, sau đó cài Command Line Tools:

xcode-select --install
xcodebuild -version

Cài CocoaPods:

gem install cocoapods
pod --version

5. Tải thư viện của dự án

5.1. Flutter packages và Pods

Từ thư mục gốc ChemSort:

flutter pub get

Nếu build iOS, cài Pods:

cd ios
pod install
cd ..

⚠️ Quan trọng: Mở ios/Runner.xcworkspace trong Xcode, không phải Runner.xcodeproj

Packages chính của dự án:

  • image - Xử lý ảnh
  • image_picker - Chụp/chọn ảnh
  • tflite_flutter - Chạy model TFLite

6. Chạy và build trên Android

6.1. Kết nối thiết bị

Bật USB debugging trên điện thoại, kết nối USB và chấp nhận tin cậy máy tính:

adb devices
flutter devices

6.2. Chạy bản debug

flutter run

Hoặc chọn thiết bị cụ thể:

flutter run -d emulator-5554

6.3. Build APK và cài lên điện thoại

Build APK theo từng kiến trúc:

flutter build apk --release --split-per-abi

APK ARM64 (thường dùng) nằm ở:

build\app\outputs\flutter-apk\app-arm64-v8a-release.apk

Cài lên điện thoại:

adb install -r build\app\outputs\flutter-apk\app-arm64-v8a-release.apk

Kiểm tra đã cài:

adb shell pm list packages | Select-String "vn.chemsort.app"

⚠️ Về chữ ký: Cấu hình hiện dùng debug signing. APK phù hợp kiểm thử nội bộ, chưa phải bản ký release cho Google Play.

Xiaomi/Redmi/POCO: Có thể cần bật thêm Cài đặt qua USB trong Tùy chọn nhà phát triển.

7. Chạy và build trên iOS

7.1. Chuẩn bị project

flutter pub get
cd ios
pod install
cd ..
open ios/Runner.xcworkspace

Trong Xcode, chọn project Runner và target ứng dụng. Chọn Team trong Signing & Capabilities để chạy trên iPhone thật.

7.2. Chạy debug

flutter devices
flutter run
flutter run -d <DEVICE_ID>

💡 Simulator dùng để kiểm tra UI. Hãy xác nhận TFLite trên iPhone thật trước khi kết luận bản iOS hoạt động.

7.3. Build bản iOS

Kiểm tra build chưa ký:

flutter build ios --release --no-codesign

Tạo IPA cần signing/team hợp lệ:

flutter build ipa --release

8. Kiểm tra sau khi cài

8.1. Kiểm tra cấu hình và mã nguồn

flutter doctor -v
flutter analyze
flutter test

8.2. Kiểm tra luồng ứng dụng thủ công

  • ✅ App mở đến màn Home, nút Bắt đầu hoạt động
  • ✅ Camera và Album chọn ảnh được
  • ✅ Ảnh được xử lý, hiển thị kết quả và độ tin cậy
  • ✅ Ngưỡng 0.5 hoạt động (độ tin cậy thấp yêu cầu chụp lại)
  • ✅ Với Nhựa, màn hình mã 1-7 hoạt động
  • ✅ Flashcard hiển thị nội dung và nguồn
  • ✅ Nút Quét vật khác quay lại luồng quét

✅ Test samples: Thử chai nhựa có mã rõ, vật kim loại và ảnh khó phân loại để kiểm tra đầy đủ.

9. Xử lý sự cố

9.1. Flutter hoặc SDK không được nhận diện

  • Chạy flutter --version và flutter doctor -v trong terminal mới
  • Kiểm tra PATH trỏ đúng flutter/bin
  • Kiểm tra SDK Location trong Android Studio
  • Thêm platform-tools vào PATH nếu adb không nhận diện

9.2. Build Android lỗi hoặc Gradle không đồng bộ

flutter clean
flutter pub get
flutter doctor -v

9.3. CocoaPods không cài hoặc iOS build lỗi

  • Xác nhận pod --version hoạt động trên macOS
  • Chạy flutter pub get rồi (cd ios && pod install)
  • Nếu đổi cấu hình iOS: flutter clean, cài Pods lại, build lại
  • Kiểm tra Strip Style vẫn là Non-Global Symbols
  • Mở ios/Runner.xcworkspace, không phải .xcodeproj

9.4. Không tìm thấy model hoặc flashcard

Xác nhận các file asset tồn tại và pubspec.yaml khai báo assets/chemsort/:

flutter clean
flutter pub get

9.5. Không mở camera hoặc album

  • Android: Cài đặt → Ứng dụng → ChemSort → Quyền → Bật Camera và Media
  • iOS: Settings → ChemSort → Bật Camera/Photos
  • Project đã có mô tả quyền trong ios/Runner/Info.plist
  • Emulator/simulator có thể không có camera; thử thiết bị thật

9.6. Không cài APK hoặc app thoát

  • INSTALL_FAILED_UPDATE_INCOMPATIBLE: Gỡ app cũ → adb uninstall vn.chemsort.app
  • Xiaomi/Redmi: Bật Cài đặt qua USB trong Dev Options
  • App thoát khi model: Kiểm tra model còn nguyên, thử thiết bị API 26+
  • iOS Simulator kết quả lạ: Test lại trên iPhone thật

10. Chuẩn bị phát hành và tùy chỉnh

10.1. Android Release

Trước khi phân phối:

  • Cấu hình khóa ký release riêng trong Gradle
  • Bảo quản keystore và mật khẩu ngoài repository
  • Cập nhật version trong pubspec.yaml
  • Xác nhận application ID phù hợp
  • Không commit keystore, mật khẩu hoặc thông tin ký

10.2. iOS Release

Để phân phối qua TestFlight:

  • Cấu hình Team, Bundle Identifier trong Xcode
  • Thêm signing certificate và provisioning profile
  • Tạo archive/IPA với cấu hình release đã ký
  • Build --no-codesign chỉ kiểm tra biên dịch, không cài được

10.3. Gỡ lỗi và hot reload

flutter run -v
flutter logs
  • Nhấn r trong terminal để hot reload
  • Nhấn R để hot restart (khởi động lại app)
  • Dùng flutter run --profile để quan sát hiệu năng

10.4. Điểm thường tùy chỉnh

  • Đường dẫn model và ngưỡng: lib/config.dart
  • Nội dung flashcard: assets/chemsort/flashcards.json
  • Ánh xạ nhãn: assets/chemsort/chemsort_mapping.json
  • Màu sắc/giao diện: lib/theme.dart
  • Thứ tự nhãn model: assets/chemsort/labels_9.txt
