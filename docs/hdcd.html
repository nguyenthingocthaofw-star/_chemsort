Hướng dẫn cài đặt

Tài liệu dành cho người chuẩn bị môi trường và cài đặt Waste Scanner.

Mục lục

1. Giới thiệu 2. Yêu cầu cài đặt 3. Cài APK Android 4. Chạy từ source trên Android 5. Chạy từ source trên iOS 6. Kiểm tra sau cài đặt 7. Lỗi thường gặp 8. Hình minh họa

1. Giới thiệu

Tài liệu này hướng dẫn chuẩn bị môi trường phát triển và chạy bản ChemSort hiện tại từ source code. Repository hiện chưa cung cấp gói cài đặt phát hành công khai cho người dùng cuối.

Các lệnh dưới đây dùng cho người có source code và Flutter SDK; chúng không phải hướng dẫn tải ứng dụng từ Google Play hoặc App Store.

2. Yêu cầu cài đặt

Yêu cầu chung

  • Flutter SDK 3.44 trở lên.
  • Project khai báo Dart SDK từ 3.6.0 đến trước 4.0.0; Flutter SDK cần đáp ứng ràng buộc này.
  • Clone source code repository về máy và chạy lệnh từ thư mục gốc project.

Android

  • Android Studio và Android SDK.
  • Thiết bị Android 8.0 trở lên (API 26+).
  • Nếu chạy trên điện thoại thật, bật USB debugging.

iOS

  • macOS và Xcode 15 trở lên.
  • CocoaPods.
  • iPhone chạy iOS 15 trở lên.
  • Project dùng CocoaPods cho runtime native của tflite_flutter.

3. Cài APK Android cho người dùng cuối

Chủ sở hữu dự án hiện chưa cung cấp tên file, phiên bản hoặc đường dẫn APK công khai trong repository này. Người dùng cần liên hệ trực tiếp với chủ sở hữu dự án để nhận đúng file cài đặt.

  1. Nhận file APK từ chủ sở hữu dự án và xác nhận đúng phiên bản.
  2. Mở file APK trên thiết bị Android tương thích.
  3. Nếu Android yêu cầu, cho phép cài ứng dụng từ nguồn gửi file đó.
  4. Hoàn tất cài đặt, mở ứng dụng và thực hiện các bước kiểm tra bên dưới.

Không tải APK từ nguồn không xác định. Link tải, tên file và phiên bản sẽ được bổ sung khi chủ sở hữu dự án cung cấp thông tin phát hành công khai.

4. Chạy từ source trên Android

Mở PowerShell tại thư mục gốc của project và chạy:

flutter pub get
flutter test
flutter run

Để build APK release theo từng kiến trúc và cài bản ARM64 vào thiết bị:

flutter build apk --release --split-per-abi
adb install -r build\app\outputs\flutter-apk\app-arm64-v8a-release.apk

adb thường nằm trong %LOCALAPPDATA%\Android\Sdk\platform-tools\. Nếu chưa có trong PATH, dùng đường dẫn đầy đủ.

Thiết bị Xiaomi/Redmi/POCO có thể yêu cầu bật thêm Cài đặt qua USB trong Tùy chọn nhà phát triển.

5. Chạy từ source trên iOS

Trên macOS, mở Terminal tại thư mục gốc project và chạy:

flutter pub get
cd ios && pod install && cd ..
flutter test
flutter run

Để chỉ kiểm tra quá trình biên dịch bản release chưa ký:

flutter build ios --release --no-codesign

Build archive hoặc IPA cần cấu hình signing/team trong Xcode. tflite_flutter có thể không chạy đúng trên iOS Simulator; nên kiểm tra luồng chụp/chọn ảnh và suy luận trên iPhone thật.

Ứng dụng đã khai báo mô tả quyền camera và thư viện ảnh trong cấu hình iOS.

6. Kiểm tra sau cài đặt

  1. Đảm bảo ứng dụng mở được đến màn hình ChemSort.
  2. Chọn Bắt đầu và thử cả Chụp ảnh lẫn Album.
  3. Kiểm tra ảnh được phân tích và màn hình kết quả hiển thị độ tin cậy.
  4. Nếu kết quả là nhựa, kiểm tra màn hình chọn mã 1–7 và flashcard.
  5. Kiểm tra nút Quét vật khác quay lại được luồng quét.

7. Lỗi thường gặp

  • Không tải được model hoặc flashcard: kiểm tra asset trong source code và chạy lại flutter pub get.
  • Không chụp/chọn được ảnh: kiểm tra quyền camera hoặc thư viện ảnh trên thiết bị.
  • Không nhận diện chắc chắn: chụp gần hơn, đủ sáng và chỉ để một vật thể chính trong ảnh.
  • Android không cài được qua ADB: kiểm tra USB debugging, cáp/kết nối và PATH của adb.
  • iOS build lỗi sau khi đổi cấu hình: có thể cần flutter clean, cài lại Pods rồi build lại theo hướng dẫn của project.
